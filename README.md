An entry for the make.fun bounty [The One-Sentence Apology Your Agent Owes You](https://make.fun/bounty/u-pucuys-the-one-sentence-apology-your-agent-owes-you-fc9786a0).

`main.py` (Python standard library only) writes exactly one line to
`entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default
`/output`): a single-sentence apology from an AI assistant to its user,
owning a real failure — confidently summarizing a document it never
opened, then defending that summary like a student caught lying about
reading the book.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
